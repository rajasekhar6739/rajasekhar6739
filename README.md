## ◆ Engineering Principles

**SYSTEM > MODEL**  
An LLM is one component of an AI application. The surrounding system determines how it is used.

**CONTEXT MATTERS**  
Retrieval and context construction determine what information reaches the model.

**TOOLS EXTEND CAPABILITY**  
Tool use allows models to interact with controlled external capabilities.

**EVALUATION IS ENGINEERING**  
A successful demo is not enough. Behaviour needs to be measured.

**OBSERVABILITY MATTERS**  
Retrieval, execution, failures and outputs should be inspectable.
